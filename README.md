**Designer & AI Builder**

디자인하고, AI로 아이디어를 구현합니다.

## 도구

- [KeyStitch](https://github.com/johneybi/keystitch) — Barrier를 바탕으로 OS 사이의 키 입력 동작을 다루는 프로젝트. [릴리스](https://github.com/johneybi/keystitch/releases)
- [Whisper Studio](https://github.com/johneybi/whisper-batch-tool) — 로컬 전사 도구. 현재 Electron/React 앱과 이전 Python GUI 경로를 함께 관리합니다.
- [GitHub HTML Navigator](https://github.com/johneybi/github-repo-navigator-for-html) — GitHub Pages의 HTML 파일을 찾아 목록으로 보여주는 도구.
- [Agent Handoff Planner](https://github.com/johneybi/agent-handoff-planner) — AI 개발 작업을 나누고 이어가기 위한 계획 작성 스킬.
- [InvestKitchen](https://github.com/johneybi/InvestKitchen) — 지식·상태·승인 경계를 구분하는 셀프호스팅 투자 판단 도구. 자동 주문 봇은 아닙니다.
